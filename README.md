## 🎮 About the Game

the cabin game is a first-person psychological horror and card-based co-op game developed by Twisted Corridor. It entered Early Access on August 27, 2026, for Windows. Designed for one to four players, it traps players inside a procedurally arranged cabin where cards, clues, room placement, and survival events determine the route to freedom.

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **the cabin game**. This trainer provides control over the shared clock, card draws, clue investigation, movement, and survival encounters. It is designed around the game's card table, player-built cabin layout, investigation system, timed escape objective, and hostile event sequences.

**Target Audience:** Players who want to practice the card and clue systems, explore cabin layouts without time pressure, learn event encounters, test co-op strategies, or complete investigations with reduced difficulty.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## ⚡ Features (v1.0)

### 🎯 Gameplay

- **Freeze Shared Clock** — Stops the shared time track from advancing while players investigate the cabin, arrange cards, or plan their escape.
- **Instant Card Draw** — Provides an immediate replacement card when the current hand or draw slot does not offer a useful option.
- **Unlimited Card Uses** — Allows supported cards to be played repeatedly without consuming the normal card-use limitation.
- **Freeze Escape Deadline** — Prevents the run from resolving when the shared clock reaches its normal deadline, giving players more time to reach the selected room.

### 📌 Investigation

- **Reveal Active Clue** — Reveals the currently active clue from the Graveyard so players can identify evidence without wasting additional turns.
- **Unlock Discovered Clues** — Marks investigation clues as discovered, helping players narrow down the correct escape room.
- **Ignore Clue Requirements** — Allows clue-related progress without requiring every associated object or room condition to be found manually.
- **Escape Room Assistance** — Highlights or identifies the currently valid escape-room candidate after the required clues have been revealed.

### 🌍 World

- **Free Room Placement** — Allows Room Cards to be positioned more freely when building and connecting the cabin.
- **No Placement Restrictions** — Removes standard doorway and connection checks when expanding the player-built cabin layout.

### 🚶 Movement

- **Player Speed** — Adjusts walking speed to make room searches, event objectives, and final escapes faster.
- **No Stamina Drain** — Prevents movement-related stamina loss during exploration and timed survival sequences.

### 📌 Survival

- **Invulnerability** — Prevents damage or death during hostile encounters and event sequences.
- **Disable Monster Pursuit** — Stops hostile entities from pursuing players while they search rooms or return to the card table.
- **Event Protection** — Reduces or disables failure conditions during event challenges, including sequences that interrupt normal card-table play.

## 📖 Detailed Feature Guide

### Movement & Exploration

Use the movement options while exploring the connected cabin and searching for clue evidence. Increased speed is useful when rooms are spread across long corridors or when an event requires reaching a location quickly. Disable movement-related options before entering online sessions if other players experience synchronization problems.

### Tools & Inventory

The game uses a card-based hand and a shared card table rather than a conventional item inventory. Card assistance affects draws, clue access, and repeated card use. The Graveyard stores clue cards, with the top clue serving as the active clue, so reveal or unlock investigation options only after confirming the current card state.

### World & Environment

Room Cards are used to build the cabin, and the resulting layout determines how players travel, search for evidence, avoid threats, and reach the final exit. Free placement options can help test alternate floor plans, but extreme layouts may cause visual or pathing issues. Save normal placement for standard runs.

### Combat & Weapons

the cabin game does not use conventional weapon-based combat. Danger comes from monsters, pursuit sequences, and event challenges that interrupt the card-table phase. Use invulnerability, monster-pursuit controls, and event protection to study these encounters without repeatedly restarting the run.
